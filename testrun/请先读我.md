# PCL 实例已接好

PCL 当前选中版本已经是 **neoforge-21.1.264**（Minecraft 1.21.1）。  
测试模组已放进该版本自己的 `mods` 文件夹，不需要再下载。

实例目录：

`%APPDATA%\.minecraft\versions\neoforge-21.1.264`

最小可运行环境只有这四个 jar：Connector、Forgified Fabric API、Debugify、synia-debugify。不要加入 YACL；3.8.2 在 Connector 2.x 上因缺少 refmap 会启动即崩，闭环结论也不依赖它。

## 组 A（现在做）

1. 打开 **PCL**
2. 确认左侧/版本是 **neoforge-21.1.264**（`PCL.ini` 里已经写成这个）
3. 启动。不要加 JVM 参数
4. 进世界，用镐连续快速敲同一格
5. 退出后执行：

```powershell
cd testrun\scripts
.\collect-snippets.ps1
```

把 `testrun\out\snippets-*.txt` 发我，并附一句组 A 观察。
